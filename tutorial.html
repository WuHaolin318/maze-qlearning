STEP 01

认识强化学习与项目

概念

学习目标

  • 理解 state、action、reward、episode 四个词
  • 知道 Q 表、epsilon-greedy、Q 更新公式的大致作用
  • 看清这个项目的文件结构

讲解

强化学习里，智能体不是在“背答案”，而是反复和环境交互：看到状态、做动作、拿奖励、再看到新状态。这样一轮一轮试错后，它才知道“什么位置该往哪走”。

本项目会逐步写出这些文件：env.py（环境）、agent.py（智能体）、train.py（训练）、evaluate.py（评估）、visualize.py（可视化）、experiments.py（实验）。

接下来每个函数单独一课：先看代码，再逐行讲解。开始前可以先打开 学习台 看一次完整训练过程。

STEP 03

env.py：__init__ 初始化环境

函数

这个函数做什么

创建环境对象时自动运行，负责记住地图尺寸、起点、终点，并立刻开始第一局。

逐行讲解

  • class GridMazeEnv: 定义一个环境类，把地图和规则打包在一起
  • def __init__(self): 每次创建环境对象时自动调用
  • self.rows = len(MAP) 地图有几行，也就是 6
  • self.cols = len(MAP[0]) 第一行有几个格子，也就是列数 6
  • self.start_pos = self._find_position(2) 扫描地图找到编码 2 的起点
  • self.goal_pos = self._find_position(3) 扫描地图找到编码 3 的终点
  • self.agent_pos = None 智能体位置先留空
  • self.reset() 调用下面的 reset，立刻把智能体放回起点

STEP 04

env.py：_find_position 找坐标

函数

这个函数做什么

输入一个数字编码，遍历地图，返回第一个匹配格子的坐标 (row, col)。

逐行讲解

  • for r in range(self.rows): 从上到下逐行扫描
  • for c in range(self.cols): 在每一行里从左到右扫描
  • if MAP[r][c] == value: 当前格子的编码等于要找的值
  • return (r, c) 找到后立刻返回坐标，函数结束

因为地图里起点和终点都只有一个，所以“找到就返回”是安全的。

函数

这个函数做什么

把智能体放回起点，并返回初始状态，表示“新的一局开始”。

STEP 06

env.py：_is_wall 判断墙和边界

函数

这个函数做什么

给一个坐标，回答“这里能不能进去”。越界也算墙，不允许走出地图。

逐行讲解

  • if r < 0 or r >= self.rows: 行号越出上下边界
  • return True 越界就当成墙，禁止进入
  • if c < 0 or c >= self.cols: 列号越出左右边界
  • return MAP[r][c] == 1 没越界时，检查是不是墙格子

STEP 07

env.py：step 执行一个动作

函数

这个函数做什么

输入动作编号（0 上、1 下、2 左、3 右），移动智能体，并返回 (新状态, 奖励, 是否结束)。

逐行讲解

  • dr, dc = ACTIONS[action] 取出该动作对应的行、列位移
  • r, c = self.agent_pos 读出当前位置
  • nr, nc = r + dr, c + dc 计算动作后的目标位置
  • if self._is_wall(nr, nc): 目标位置是墙或越界
  • return self.agent_pos, REWARD_WALL, False 位置不变、给惩罚、本局不结束
  • self.agent_pos = (nr, nc) 正常移动，更新位置
  • if self.agent_pos == self.goal_pos: 到达终点
  • return ..., REWARD_GOAL, True 给 +10，本局结束
  • return ..., REWARD_STEP, False 普通移动，小惩罚，继续

STEP 10

agent.py：__init__ 创建 Q 表

函数

这个函数做什么

创建智能体，准备一张全 0 的 Q 表，并保存所有超参数。

逐行讲解

  • alpha 学习率：每次更新时新信息占多大比重
  • gamma 折扣因子：未来奖励打多少折
  • epsilon 当前探索概率：越大越爱随机走
  • epsilon_min 探索概率下限，防止完全停止探索
  • epsilon_decay 每局结束后 epsilon 乘的衰减系数
  • random.Random(seed) 独立随机源，固定 seed 可复现
  • np.zeros((n_rows * n_cols, n_actions)) 36 行 4 列的全零表

STEP 11

agent.py：state_to_index 坐标转下标

函数

这个函数做什么

把二维坐标 (row, col) 转成一维下标，因为 Q 表只有一维的行索引。

逐行讲解

  • row, col = state 把坐标拆成行和列
  • row * self.n_cols + col 第 row 行前面有 row 整行，再加上第 col 列

例如 (1, 2) 会变成 1 × 6 + 2 = 8，正好是 Q 表的第 8 行。

STEP 12

agent.py：choose_action 选动作

函数

这个函数做什么

用 epsilon-greedy 策略选动作：有时随机探索，有时选 Q 值最大的动作。

逐行讲解

  • greedy=False 训练时允许探索；评估时传 True 只利用
  • random() < epsilon 以 epsilon 概率进入探索分支
  • randint(0, 3) 随机返回一个动作编号
  • np.argmax(q_table[index]) 找出 Q 值最大的动作下标

探索帮它发现新路径，利用帮它走当前最优路径，epsilon 决定两者的比例。

STEP 13

agent.py：update 更新 Q 值

函数

这个函数做什么

用一次经验 (state, action, reward, next_state, done) 更新 Q 表中的一个值。

逐行讲解

  • s_idx 当前状态在 Q 表里的行
  • ns_idx 下一个状态在 Q 表里的行
  • if done: 本局结束，没有下一个状态，未来回报按 0 算
  • np.max(q_table[ns_idx]) 下一个状态里最好的动作值多少
  • td_target = reward + gamma * best_next_q 目标值，比旧估计更接近真相
  • old_q + alpha * (td_target - old_q) 往目标值方向走一小步

手算例子

Q 初始 = 0，奖励 = 1，下一个状态不是终点
alpha = 0.5，gamma = 0.9
target = 1 + 0.9 × 0 = 1
新 Q = 0 + 0.5 × (1 - 0) = 0.5

STEP 14

agent.py：decay_epsilon 探索衰减

函数

这个函数做什么

每局结束后让 epsilon 变小一点，但不会低于 epsilon_min。

逐行讲解

  • self.epsilon * self.epsilon_decay 每次乘 0.999，越乘越小
  • max(...) 防止 epsilon 低于 0.05，保留少量探索

前期多探索，后期多利用，这是训练能稳定收敛的关键之一。

STEP 15

train.py：训练循环

函数

这个函数做什么

把“选动作 → 环境反馈 → 更新 Q 表”串起来，反复训练很多局。

逐行讲解

  • state = env.reset() 新的一局从起点开始
  • action = agent.choose_action(state) 智能体选动作
  • env.step(action) 环境执行并返回新状态、奖励、是否结束
  • agent.update(...) 把这次经验写进 Q 表
  • if done: 本局结束，记录是否成功并退出本局
  • agent.decay_epsilon() 每局结束降低探索概率

evaluate.py：run_policy 跑一局

函数

这个函数做什么

按给定策略跑一局，返回（是否成功, 走的步数）。

逐行讲解

  • greedy=greedy 评估时传 True，完全关闭探索
  • state, _, done = env.step(action) 只用状态和 done，不需要奖励
  • if done: break 到达终点就提前结束
  • return state == env.goal_pos, step + 1 是否成功 + 用了多少步

evaluate.py：统计成功率

函数

这个函数做什么

连续跑 100 局，统计成功率和平均步数，作为“学得好不好”的客观指标。

逐行讲解

  • successes.append(ok) 记录这一局成没成功
  • sum(successes) / len(successes) 成功局数除以总局数

experiments.py：单变量实验

实验

这个循环做什么

一次只改一个超参数（这里是 alpha），其余不变，比较最终成功率。

逐行讲解

  • for alpha in [0.05, 0.1, 0.3]: 依次尝试三个学习率
  • QLearningAgent(..., alpha=alpha) 每次只换 alpha
  • train_agent(env, agent, 1500) 每组训练相同局数
  • evaluate(agent) 用同一套评估函数比较结果

预期输出

alpha = 0.05 | 最终成功率 100.0% | 平均步数 10.0
alpha = 0.1  | 最终成功率 100.0% | 平均步数 10.0
alpha = 0.3  | 最终成功率 100.0% | 平均步数 10.0

小地图上几种 alpha 都能收敛；换成更大的地图，差异会更明显。

总结与下一步

收尾

现在你能讲清楚什么

  • Q 表：每个状态每个动作的长期回报估计
